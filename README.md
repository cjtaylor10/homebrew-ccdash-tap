# homebrew-ccdash-tap

Homebrew tap for [ccdash](https://github.com/cjtaylor10/ccdash) — local desktop dashboard for managing Claude Code sessions, projects, ports, and plans.

## Install

```bash
brew tap cjtaylor10/ccdash-tap
brew install ccdash
```

## Update

```bash
brew update
brew upgrade ccdash
```

See the [main ccdash repository](https://github.com/cjtaylor10/ccdash) for documentation and source.
